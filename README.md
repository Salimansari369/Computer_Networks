## About the Repository

This repository contains practical assignments, implementations, and network analysis completed as part of the **Computer Networks Laboratory** course.

The repository focuses on understanding fundamental networking concepts, communication protocols, network traffic management, routing algorithms, and network analysis tools through hands-on experiments and programming.

The practicals include implementations in C programming language and network analysis using Wireshark.

## How to Run C Programs

### 1. Clone this repository:

`ash
git clone https://github.com/Salimansari369/Computer_Networks.git
`

### 2. Navigate to the repository:

`ash
cd Computer_Networks
`

### 3. Compile a C program using GCC:

`ash
gcc filename.c -o output
`

### 4. Execute the compiled program:

`ash
./output
`

> **Note:** For TCP and UDP client-server programs, run the server program first in one terminal window, and then execute the client program in a separate terminal window. Ensure both use compatible IP addresses and port numbers.

## Learning Outcomes

Through these practical experiments, the following key objectives are achieved:

- Fundamentals of computer networks and network communication layers.
- Working of connection-oriented (TCP) and connectionless (UDP) transport protocols.
- Client-server architecture and network socket programming in C.
- Network traffic capturing, packet filtering, and protocol analysis using Wireshark.
- Inspection of DNS queries, domain resolutions, and HTTPS handshakes.
- Implementation of Sliding Window Protocol for reliable data transfer and flow control.
- Traffic shaping and rate limiting using Token Bucket and Leaky Bucket algorithms.
- Dynamic routing principles and Bellman-Ford computation in Distance Vector Routing.
